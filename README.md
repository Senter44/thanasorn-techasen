# Zen Garden Portfolios

Two interactive portfolio experiences built around a Japanese zen-garden theme.

## Projects

- [`original-zen-garden/`](./original-zen-garden/) — illustrated garden with animated interactions and portfolio content.
- [`3d-zen-garden/`](./3d-zen-garden/) — Three.js garden with selectable 3D objects, portfolio panels, and an optional WebGPU fluid simulation.

## Live sites

- [Original illustrated garden](https://thanasorn-portfolio-study.mlbs-9651.chatgpt.site/)
- [Interactive 3D garden](https://thanasorn-zen-garden-3d.mlbs-9651.chatgpt.site/)

Each project is self-contained and includes its own setup details, tests, assets, and local preview instructions. See [`OPEN-PORTFOLIOS.md`](./OPEN-PORTFOLIOS.md) for a quick guide.
