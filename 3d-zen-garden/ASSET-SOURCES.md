# Preview material sources

The optional high-detail preview uses these 1K CC0 textures from Poly Haven:

- [Rock 01](https://polyhaven.com/a/rock_01) — diffuse and OpenGL normal maps, by Rob Tuytel.
- [Mossy Rock](https://polyhaven.com/a/mossy_rock) — diffuse and OpenGL normal maps, by Rob Tuytel.

Both texture sets are stored locally in `dist/assets/materials/`; the portfolio does not depend on Poly Haven at runtime. The original garden model and portfolio content remain unchanged.
